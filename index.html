    ⚙️ 识别引擎设置

    DeepSeek：填 key 保存即可用。官方接口允许浏览器跨域（实测对 file:// 的 Origin: null 也放行），无需代理或服务器；模型 deepseek-flash 支持图片输入，按量计费。若个别浏览器仍拦截本地文件请求，用 python -m http.server 8000 托管即可。
    智谱 GLM：接口未开放 CORS，需先在本文件夹运行 python glm-proxy.py，端点会自动填为本地代理；免费视觉模型 glm-4.6v-flash。
    密钥仅保存在本机浏览器存储中，不会随应用文件分发，也不会发送到你配置之外的地址。
